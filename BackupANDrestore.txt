## What this now backs up beyond the previous version

| New addition | What it captures |
|---|---|
| `registry-installed.csv` | Every installed app from registry — the complete ground truth list |
| `reg-uninstall-hklm/hkcu.reg` | Full registry uninstall keys for both system and user |
| `reg-services.reg` | All Windows services snapshot |
| `reg-fonts.reg` | Installed fonts registry entries |
| `wmi-products.csv` | WMI product list — catches MSI-installed apps winget misses |
| `appx.csv` | All Store/AppX packages with versions |
| `installed-all.csv` | PowerShell PackageManagement full dump |
| `env-machine.json` + `env-user.json` | All environment variables |
| `path-entries.txt` | Every PATH entry individually |
| `vscode-settings.json` + `vscode-keybindings.json` | Full VS Code config |
| `gitconfig.bak` | Git identity and aliases |
| `ssh-keys/` | All SSH keys with permissions locked down on restore |
| `wslconfig.bak` | WSL2 memory/CPU tuning |
| `ps-history.txt` | PowerShell command history |
| `services.csv` + `scheduled-tasks.csv` | Human-readable service and task snapshots |
| `drives.csv` | Drive layout reference |
| `node-version.txt` + `python-version.txt` | Version reference for manual installs |

> The CSVs, REG files, and version logs don't auto-reinstall everything — but the restore liner reads `registry-installed.csv` at the end and prints exactly which apps are still missing so you have a precise checklist for the handful of things no package manager can automate (drivers, GIGABYTE software, licensed apps).
